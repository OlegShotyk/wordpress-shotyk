Розрахунково-графічна робота з дисципліни «Операційні системи»: розгортання WordPress за допомогою Docker Compose. Виконав Олег Шотик, НУ «Львівська політехніка», 2026.

Архітектура

Сайт працює у трьох контейнерах, з'єднаних мостовою мережею app-network:

КонтейнерОбразРоль
db-shotykmysql:8.0База даних (том dbdata)
wordpress-shotykwordpress:5.1.1-fpm-alpinePHP-FPM, порт 9000
webserver-shotyknginx:1.15.12-alpineВебсервер, порти 80 → 443, SSL

Що зроблено

  • Локальний домен oleg-shotyk.local у файлі hosts.
  • Самопідписаний SSL-сертифікат RSA 2048, створений OpenSSL на 365 днів.
  • Nginx перенаправляє HTTP на HTTPS (код 301) і передає PHP-запити до php-fpm.
  • Паролі бази даних винесені у файл .env, який не потрапляє в Git і Docker-образи.
  • Однакова конфігурація розгорнута на Ubuntu 26.04 і Windows 10; машини з'єднані внутрішньою мережею VirtualBox.

Docker Compose дозволяє підняти весь стек однією командою docker compose up -d на будь-якій ОС.
